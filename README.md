## 🚀 Deployment on Vercel

This website is configured for 1-click deployment on **[Vercel](https://vercel.com)**.

1. Go to [Vercel](https://vercel.com/new).
2. Import this GitHub repository: `badrelhamdaoui45/WEWE`.
3. The configuration in `vercel.json` will automatically set:
   - **Output Directory**: `famdt.com/www.famdt.com`
   - **URL Rewrites**: Handles query parameter routing seamlessly (`?p=...`).
4. Click **Deploy**.

## 💻 Local Development

To run the website locally:

```bash
# Start the local server
npm start
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
